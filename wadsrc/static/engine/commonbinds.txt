// PC branch: Raze's names. These two came from GZDoom's pad bindings as
// "+attack" and "+altattack", which Raze does not have - every press printed
// "Unknown command". ltrigger is the VR off-hand trigger, so alt fire never
// worked from it. FGameConfigFile::DoKeySetup repairs saved configs.
rtrigger +Fire
ltrigger +Alt_Fire

// PC branch: "+crouch", held for as long as the button is. This line came
// from GZDoom's pad bindings as a bare "crouch", which fires once per press:
// the VR X button sends this key, so X crouched for an instant and could not
// hold you swimming down (a player, 29 Sep 2026). FGameConfigFile::DoKeySetup
// repairs configs that saved the old line.
lthumb +crouch
// PC branch: the off-hand stick click. Their VR layer routes it here and
// leaves it unbound - "No Default Binding" in VrInputDefault.cpp - and it is
// the only way to reach Shadow Warrior's quad shotgun and nuke, which toggle
// by re-selecting the weapon already in hand. Blood, Duke, Redneck and
// Exhumed all handle WeaponSel_Alt too, so this is worth having everywhere.
rthumb weapalt
